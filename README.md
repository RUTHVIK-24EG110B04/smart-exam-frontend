# Smart Exam Prep - Frontend (React + Vite)

## Requirements
- Node.js 18+

## Setup
```
npm install
npm run dev
```
Opens at http://localhost:5173

The backend URL is set in `.env`:
```
VITE_API=http://localhost:8081
```
Start the Spring Boot backend first (see backend README).

## Login
- Admin: admin@exam.com / admin123
- Students: use "Create account" on the login page.
